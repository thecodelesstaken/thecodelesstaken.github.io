The site's own code does not use analytics, advertising trackers, behavioral profiling, cookies, or third-party webfonts. The color-mode control stores one preference in your browser. Our code does not transmit that preference.

## Hosting

This is a static site hosted by [GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages). GitHub states that it logs and stores a visitor's IP address for security whenever a GitHub Pages site is visited. GitHub controls that processing under its [General Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). We do not operate the hosting servers or set GitHub's retention policies.

## Email

If you email us, we receive your address, message, and any material you include. We use that information to respond, evaluate submissions or corrections, and retain correspondence when it remains relevant to the publication.

If we add a newsletter or other service that collects personal information, its purpose, provider, and retention terms will be disclosed before collection begins.

Questions about privacy can be sent to [contact@thecodelesstaken.com](mailto:contact@thecodelesstaken.com).
